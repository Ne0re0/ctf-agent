CTF SANDBOX TOOLS REFERENCE
============================
All tools pre-installed in the sandbox. cat /tools.txt to view this file.

== NETWORKING ==
nc (netcat)        TCP/UDP connections. nc host port <<'EOF' for heredoc sessions.
curl               HTTP client. -s silent, -k skip TLS, -d data, -H header.
wget               HTTP download. wget -O file url.
nmap               Port scanner. nmap -sV host, nmap -p- host.
ping               ICMP reachability test. ping -c 4 host.

== ACTIVE DIRECTORY / WINDOWS ==
impacket           SMB, Kerberos and AD utilities: impacket-secretsdump, impacket-psexec, etc.
nxc                NetExec for SMB, LDAP, WinRM and more. nxc smb host -u user -p pass.
smbclient          Samba SMB client. smbclient -L //host -N lists shares anonymously.
rpcclient          Samba RPC client. rpcclient -U '' -N host for anonymous RPC.
smbclientng        Interactive SMB client. smbclientng -h for options.
enum4linux-ng       SMB and LDAP enumeration. enum4linux-ng -A host.
kerbrute           Kerberos user enumeration. kerbrute userenum --dc host -d domain users.txt.
ldapsearch         LDAP queries. ldapsearch -x -H ldap://host -b 'dc=example,dc=com'.
evil-winrm         WinRM shell. evil-winrm -i host -u user -p pass.
bloodhound-python  Collect AD data for BloodHound. bloodhound-python -h for options.
bloodyAD           Active Directory privilege changes and enumeration. bloodyAD --help.

== BINARY ANALYSIS ==
file               Identify file type. file binary
strings            Extract printable strings. strings -n 8 binary
xxd                Hex dump. xxd file | head, xxd -r to reverse.
hexdump            Hex dump. hexdump -C file.
binwalk            Firmware/embedded extraction. binwalk -e file to extract.
objdump            Disassembly. objdump -d binary (from binutils). Foreign arch:
                   objdump -m <arch> or the multi-arch binutils (binutils-multiarch).
readelf            ELF header info. readelf -a binary.
nm                 Symbol listing. nm binary.

== DEBUGGERS / TRACING ==
gdb / pwndbg       gdb with pwndbg (multi-arch). gdb ./bin; checksec, vmmap, heap, bins,
                   telescope, context, cyclic, search. Non-interactive:
                   gdb -q -batch -ex 'b main' -ex r -ex 'heap' ./bin
gdb-multiarch      Plain gdb for any arch, without pwndbg.
gdbserver          Remote debugging target. gdbserver :1234 ./bin
pwninit            Patch a pwn binary to its given libc/ld: pwninit --bin chall --libc libc.so.6
                   (fetches ld + debug symbols, writes chall_patched and solve.py).
patchelf           Set interpreter/rpath by hand. patchelf --set-interpreter ./ld.so ./bin
ltrace             Library call tracer. ltrace ./binary
strace             System call tracer. strace ./binary
radare2            Reverse engineering. r2 binary, then aaa; pdf @main; afl

== EMULATION (foreign architectures) ==
qemu-<arch>        User-mode: run a foreign Linux binary. Arches: x86_64, i386, arm, aarch64,
                   mips, mipsel, mips64el, ppc, ppc64le, riscv64, s390x, sparc64...
                   Dynamic binaries need their libc: qemu-arm -L /usr/arm-linux-gnueabihf ./bin
                   (base libs - libc, libstdc++, libgcc_s, libatomic, libgomp - in
                   /usr/<triplet>/lib for: x86_64-linux-gnu, i686-linux-gnu,
                   arm-linux-gnueabihf, arm-linux-gnueabi, aarch64-linux-gnu, mips-linux-gnu,
                   mipsel-linux-gnu, mips64el-linux-gnuabi64, powerpc-linux-gnu,
                   powerpc64le-linux-gnu, riscv64-linux-gnu, s390x-linux-gnu, sparc64-linux-gnu)
                   or the challenge's own: -L . / patched with pwninit. Other libs (libssl,
                   zlib...) are not there: use the ones shipped with the challenge.
                   Static variants: qemu-<arch>-static. binfmt is not set: call qemu explicitly.
                   Debug: qemu-arm -g 1234 ./bin & then gdb ./bin -ex 'target remote :1234'
                   pwntools: process(['qemu-arm', '-L', '/usr/arm-linux-gnueabihf', './bin'])
qemu-system-<arch> Full-system emulation (firmware, kernels): x86_64, i386, arm, aarch64, mips*,
                   ppc*, riscv64, s390x, sparc*... -nographic -kernel ... ; -s -S for gdb on :1234.
qemu-img           Disk image conversion/inspection. qemu-img info disk.qcow2
keystone (python)  Assembler for any arch (x86, ARM, ARM64, MIPS, PPC, SPARC, SystemZ...):
                   python3 -c "from keystone import *; print(bytes(Ks(KS_ARCH_ARM, KS_MODE_ARM).asm('mov r0, #1')[0]).hex())"

== NOTES ==
- Each sandbox has its own virtual clock. `date -u -s '2001-02-03 04:05:06'`
  changes the time seen by dynamically linked processes in that sandbox.
  `date -u` shows it; `LD_PRELOAD= date -u` shows the host's real time.
  The setting is stored in /challenge/workspace/.ctf-clock and lasts for this run.
  Static binaries and programs using direct clock syscalls may see the real time.
- Sandbox runs ARM64. Do NOT execute x86/x86-64 binaries locally.
  Use Ghidra tools for RE, and interact with remote services for dynamic analysis.
- Need a package not listed? Run `pip install <pkg>` or `uv pip install <pkg>`.
- Distfiles are at /challenge/distfiles/ (read-only)
- Write generated/repaired files to /challenge/workspace/ (writable)
- Services on the host are reachable via host.docker.internal (bridge networking).
- RsaCtfTool is at /opt/RsaCtfTool/
- CADO-NFS is at /opt/cado-nfs/
